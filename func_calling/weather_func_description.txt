This function provides the real-time weather of a location by 
providing the zipcode of the given location.
This function requires zipcode as an argument, however user's often
provide location names instead of zipcodes.

If a location is received, we should provide the zipcode of that location
for the function to run properly.

Example:
Input: What is the weather in new delhi?
Output: New Delhi zipcode is 110001, so function should use that as an argument.
